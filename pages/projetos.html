Tudo sobre paternidade

O objetivo da atividade foi a criação de um site desenvolvido com o objetivo de compartilhar informações e dicas que possam ajudar pais e responsáveis durante as diferentes fases da criação de um filho. O site apresenta conteúdos sobre as etapas da paternidade, recomendações de filmes, séries, documentários e livros relacionados ao tema, além de orientações sobre os cuidados básicos com bebês, como alimentação, higiene, sono seguro e vacinação. O site foi desenvolvido utilizando HTML e CSS, com o objetivo de colocar em prática os conhecimentos adquiridos nas aulas. Seu design utiliza cores suaves em tons pastel e procura reunir informações úteis de maneira simples, organizada e visualmente agradável.

Semana da arte moderna de 22

Este projeto consiste no desenvolvimento de uma página web sobre a obra Soror Dolorosa, do escultor Victor Brecheret. O site apresenta informações sobre a escultura, suas características, seu significado e sua relação com a Semana de Arte Moderna de 1922. Para o desenvolvimento da página, foram utilizados HTML e CSS, explorando diferentes fontes e uma paleta de cores escolhida para criar uma identidade visual harmoniosa e agradável. O projeto teve como objetivo praticar os conhecimentos de desenvolvimento web e demonstrar como a combinação de cores, fontes e organização dos elementos podem contribuir para a apresentação de informações artísticas.

Desculpas Express

O 'Desculpas Express' é um projeto que apresenta uma plataforma criada para oferecer sugestões de mensagens para diferentes situações do cotidiano, como atrasos, esquecimentos, compromissos perdidos e respostas demoradas. O site foi desenvolvido utilizando HTML, CSS e Bootstrap, contando com quatro páginas principais: Início, Serviços, Sobre Nós e Contato. Entre os elementos utilizados estão uma navbar responsiva, cards, botões, formulário, sistema de grid e modais com informações adicionais sobre os serviços. Também foi criada uma seção especial de promoção para apresentar uma oferta. O projeto tem como objetivo colocar em prática os conhecimentos de desenvolvimento web, explorando a estruturação de páginas, a estilização com CSS e a utilização dos componentes do Bootstrap para criar um site organizado, atrativo e adaptável a diferentes tamanhos de tela.
